CampusOS Development Hub

You are viewing this directory via VS Code Live Server (port 5500). Because CampusOS is a full-stack React & Express SaaS application, it must be launched via the Vite development server.

💡
Why did port 5500 show a folder listing?
Port 5500 is VS Code's Live Server serving static files. The modern React frontend runs on Vite (Port 5173) with Hot Module Replacement, and the backend runs on Express (Port 5000).
🖥️ Open React Client
Runs at http://localhost:5173 with full interactive dashboards.
⚡ Backend API Health
Runs at http://localhost:5000/api/v1 with Socket.io real-time bus.
Terminal Command to Start CampusOS:
# 1. Start the React Frontend:
cd client && npm run dev
# 2. Start the Backend API (in a 2nd terminal):
cd server && npm run dev
Launch CampusOS Client (http://localhost:5173) →
